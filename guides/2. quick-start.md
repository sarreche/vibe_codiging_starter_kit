# 🚀 Quick Start Guide

1. Open the `/projects` folder.
2. Choose a project (`color-mood`, `magic-quotes`, `mini-pong`).
3. Run the file:
   - For Python: open terminal, type `python file.py`
   - For HTML: double click the `.html` file
4. Make a small change (color, text, number).
5. See what happens!

💡 Remember: It's not about perfection, it's about fun.
