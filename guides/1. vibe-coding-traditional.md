# 🌈 Vibe Coding Intro

## 🚀 What is Vibe Coding?
Vibe Coding is not about lessons or strict rules.  
It’s about playing with code like digital clay, experimenting without fear, and enjoying the surprises.

## ✨ The Philosophy
1. Open a project → press play and watch.  
2. Make a small change → a color, a number, a word.  
3. Observe the magic → congrats, you’re already coding!  

Here there are no errors, only experiments. Every result is part of the game.

---

## 🛠️ How to Run the Projects

### For Python projects (Color Mood, Mini Pong):
1. Download and install [Python](https://www.python.org/downloads/).  
2. Open the project folder.  
3. Run the file:  
   - On Windows/Mac: double-click the `.py` file  
   - Or open a terminal/command line and type:  
     `python file_name.py`  
4. If the project asks for extra libraries (like `pygame`), install them:  
   ```
   pip install pygame
   ```

### For HTML/JavaScript projects (Magic Quotes):
1. Open the project folder.  
2. Double-click the `.html` file.  
3. It will open directly in your web browser.  

---

## ⚡ Tips for Beginners
- If you see a black window with text, don’t panic: that’s the console.  
- If something doesn’t work, check if Python is installed or try again in another browser.  
- Look for comments inside the code (`#` in Python, `//` in JavaScript). They guide you to what you can change safely.
