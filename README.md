# 🎉 Vibe Coding Kit

Welcome to the **Vibe Coding Kit** ✨

This kit is designed for non-technical people who want to *play with code* without fear.
You don’t need to be a programmer — just curiosity and a bit of time.

## 📂 What’s inside?
- **/projects**
  - *color-mood*: change background colors with one click.
  - *magic-quotes*: random inspirational quotes in your browser.
  - *mini-pong*: a retro game you can edit and play.

- **/templates**
  - Cheatsheet with quick tips.
  - Creative challenges to inspire you.

- **/guides**
  - Quick start guide.
  - Vibe Coding Intro (philosophy + how-to).
  - Vibe Coding with IA.

## 🚀 How to start?
1. Open the `/guides` folder.
2. Read **Quick Start Guide**.
3. Go to `/projects` and pick one.
4. Run it → Make a small change → Enjoy!
5. You can use IA support to help you during the small changes, and again → Enjoy!

## 💡 Remember
- No errors, only experiments.
- Small changes = big wins.
- Share your creations!
