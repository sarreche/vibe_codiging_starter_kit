# 📘 Vibe Coding Cheatsheet

### Python
- Run script: `python file.py`
- Print to screen: `print("Hello!")`
- Change colors: use hex codes like `#FF5733`

### JavaScript (HTML in browser)
- Open `.html` file in browser to run
- Use `console.log("message")` for debugging

### General tips
- Experiment changing numbers or text
- Save copies with different names
- Errors are discoveries!
